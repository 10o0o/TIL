# Archive and Migration Policy

현재 `content/`에는 v1 방식으로 작성한 강의 중심의 긴 노트와 개념 노트가 섞여 있습니다.

이 자료는 삭제 대상이 아니라 다음 역할을 하는 **원본 학습 기록과 마이그레이션 소스**입니다.

- 과거에 무엇을 배웠는지 확인
- 이전 설명과 예제 재사용 후보 탐색
- 오개념과 이해 변화 추적
- 새 canonical note를 만들 때 비교 자료로 사용

## 지금 하지 않는 작업

- 모든 기존 문서를 한꺼번에 재작성
- 과거 날짜의 TIL 소급 작성
- 파일 수를 맞추기 위한 대량 이동
- 긴 문서가 있다는 이유로 숙달 상태 부여
- 링크 검증 없이 원본 경로 변경

## 필요할 때만 마이그레이션

다음 상황에서 관련 파일만 선택적으로 처리합니다.

1. 같은 개념이 새 강의에서 다시 등장한다.
2. 현재 개념의 선수지식으로 필요하다.
3. 여러 노트의 설명이 충돌하거나 중복된다.
4. 외부에 공개할 canonical note가 필요하다.

## 마이그레이션 절차

```text
관련 content 파일 검색
→ 유효한 설명과 예제 후보 추출
→ 학습자의 closed-book 설명과 비교
→ 숫자·수식·코드 검증
→ concepts의 단일 문서에 통합
→ 필요하면 labs 추가
→ progress와 TIL 갱신
→ 기존 파일은 보존
```

## 물리적 이동을 미루는 이유

기존 문서에는 상대경로 이미지와 문서 링크가 있을 수 있습니다. 대량 이동은 내용보다 링크 복구 작업을 늘릴 수 있으므로, canonical 구조가 안정된 뒤 별도 변경으로 수행합니다.

`content/`에 신규 강의 노트를 추가하지 않고 새 학습은 `concepts/`, `til/`, `labs/`, `reviews/`에서 진행합니다.
