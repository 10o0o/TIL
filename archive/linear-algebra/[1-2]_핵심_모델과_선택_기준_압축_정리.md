# 핵심 머신러닝 모델과 선택 기준 압축 정리

## 오늘의 질문

- 선형 회귀와 로지스틱 회귀는 무엇이 같고 무엇이 다를까?
- KNN, 결정 트리, K-Means는 각각 무엇을 기준으로 판단할까?
- 특성 스케일링(feature scaling)은 어떤 모델에서 중요할까?
- PCA와 SVD는 어떻게 연결될까?
- 새로운 문제를 만났을 때 어떤 모델을 첫 후보로 선택해야 할까?

## 핵심 결론

모델을 선택할 때는 이름을 외우기보다 각 모델의 **판단 기준, 표현할 수 있는 관계, 민감한 요소, 계산 비용을** 먼저 이해해야 한다.

> 선형 모델은 특성의 가중합, KNN은 이웃과의 거리, 결정 트리는 반복적인 조건, K-Means는 중심점과의 거리, PCA는 데이터의 분산이 큰 방향을 기준으로 작동한다.

최종 모델은 설명 가능성, 데이터 크기와 차원, 스케일, 비선형성 같은 조건을 바탕으로 후보를 정한 뒤 Validation 데이터나 교차 검증으로 선택한다.

## 전체 지도

이번 문서에서는 다섯 모델 계열과 여섯 가지 대표 방법을 다룬다.

```text
머신러닝
├── 지도학습
│   ├── 선형 모델
│   │   ├── Linear Regression   → 회귀
│   │   └── Logistic Regression → 분류
│   ├── KNN
│   │   ├── KNN Regression
│   │   └── KNN Classification
│   └── Decision Tree
│       ├── Regression Tree
│       └── Classification Tree
└── 비지도학습
    ├── K-Means → 군집화
    └── PCA     → 차원 축소
```

앞 문서와 연결하면 학습 순서는 다음과 같다.

```text
[1-1] 무슨 문제인가?
      ↓
회귀 / 분류 / 군집화 / 차원 축소
      ↓
[1-2] 그 문제를 어떤 방법으로 풀어 볼까?
      ↓
Linear / Logistic / KNN / Tree / K-Means / PCA
```

각 모델을 볼 때 다음 네 가지 질문을 반복하면 차이를 정리하기 쉽다.

1. 무엇을 기준으로 판단하는가?
2. 어떤 형태의 관계를 표현할 수 있는가?
3. 스케일, 이상치, 차원, 하이퍼파라미터 중 무엇에 민감한가?
4. 어떤 상황에서 첫 후보로 시도할 만한가?

## 선형 모델

### 특성의 가중합으로 예측한다

**선형 모델(linear model)은** 각 특성(feature)에 가중치(weight)를 곱한 뒤 모두 더한다.

특성이 $d$개인 샘플 하나에 대한 기본식은 다음과 같다.

$$
\hat{y}
=
w_1x_1+w_2x_2+\cdots+w_dx_d+b
=
\mathbf{w}^\top\mathbf{x}+b
$$

- $x_j$: $j$번째 입력 특성
- $w_j$: $j$번째 특성의 가중치 또는 계수
- $b$: 절편 또는 편향(bias)
- $\hat{y}$: 모델의 예측값

샘플이 $n$개인 전체 데이터는 행렬 형태로 계산할 수 있다.

$$
\hat{\mathbf{y}}=X\mathbf{w}+b
$$

각 항의 크기(shape)는 다음과 같다.

| 항 | 크기 | 의미 |
| --- | --- | --- |
| $X$ | $n\times d$ | 샘플 $n$개, 특성 $d$개 |
| $\mathbf{w}$ | $d\times 1$ | 특성별 가중치 |
| $X\mathbf{w}$ | $n\times 1$ | 샘플별 가중합 |
| $b$ | 스칼라 | 각 샘플의 가중합에 더하는 절편 |
| $\hat{\mathbf{y}}$ | $n\times 1$ | 샘플별 예측값 |

$X\mathbf{w}$에서는 $X$의 특성 축 $d$와 $\mathbf{w}$의 행 축 $d$가 수축한다. 그 결과 샘플 축 $n$만 남아 각 샘플마다 예측값 하나를 얻는다.

### 작은 집값 예측 예제

입력 특성을 다음처럼 정의하자.

$$
x_1=\text{면적}(\mathrm{m}^2),
\qquad
x_2=\text{역과의 거리}(\mathrm{km}),
\qquad
x_3=\text{건물 연식}(\text{년})
$$

예측 가격의 단위를 억 원으로 두고, 모델이 다음 식을 학습했다고 가정한다.

$$
\hat{y}
=
0.08x_1-0.3x_2-0.05x_3+1.2
$$

면적이 $50\,\mathrm{m}^2$, 역과의 거리가 $0.5\,\mathrm{km}$, 건물 연식이 10년이면 예측값은 다음과 같다.

$$
\begin{aligned}
\hat{y}
&=
0.08(50)-0.3(0.5)-0.05(10)+1.2 \\
&=
4-0.15-0.5+1.2 \\
&=
4.55
\end{aligned}
$$

$w_1=0.08$이라는 것은 다른 특성이 같을 때 면적이 $1\,\mathrm{m}^2$ 증가하면 모델의 예측 가격이 $0.08$억 원 증가하는 구조라는 뜻이다. 다만 실제 데이터에서 특성끼리 강하게 연관되어 있으면 계수를 단순한 인과 효과로 해석해서는 안 된다.

### 왜 선형 모델이라고 부를까?

특성이 하나면

$$
\hat{y}=wx+b
$$

이므로 2차원 좌표에서 직선이 된다. 특성이 두 개면

$$
\hat{y}=w_1x_1+w_2x_2+b
$$

이므로 3차원 공간에서 평면이 된다. 특성이 더 많으면 직접 시각화하기 어렵지만, 특성의 가중합으로 하나의 평면적인 관계를 만든다는 원리는 같다.

### 선형 변환과 아핀 변환

엄밀하게 구분하면

$$
X\mathbf{w}
$$

은 선형 변환(linear transformation)이고,

$$
X\mathbf{w}+b
$$

처럼 절편을 더한 연산은 아핀 변환(affine transformation)이다.

머신러닝과 딥러닝에서는 절편이 포함되어도 관습적으로 Linear Model이나 Linear Layer라고 부르는 경우가 많다. PyTorch의 `nn.Linear`도 기본적으로 다음 형태를 계산한다.

$$
\mathbf{y}=XW^\top+\mathbf{b}
$$

PyTorch 문서의 가중치 저장 방향 때문에 수식에 $W^\top$가 나타날 수 있지만, 핵심은 입력과 가중치를 행렬곱한 뒤 편향을 더한다는 점이다.

### 선형 회귀

**선형 회귀(Linear Regression)는** 가중합의 결과를 연속적인 예측값으로 사용한다.

$$
\hat{y}=\mathbf{w}^\top\mathbf{x}+b
$$

출력이 $534.3$이면 그 값을 그대로 예측값으로 사용하므로 집값, 기온, 매출과 같은 회귀 문제에 적합하다.

학습 과정에서는 보통 실제값 $y_i$와 예측값 $\hat{y}_i$의 차이를 줄이는 방향으로 $\mathbf{w}$와 $b$를 찾는다. 대표적으로 잔차 제곱합을 최소화한다.

$$
\min_{\mathbf{w},b}
\sum_{i=1}^{n}
\left(y_i-\hat{y}_i\right)^2
$$

### 로지스틱 회귀

**로지스틱 회귀(Logistic Regression)는** 이름에 Regression이 있지만 주로 분류에 사용한다.

먼저 선형 결합을 계산한다.

$$
z=\mathbf{w}^\top\mathbf{x}+b
$$

$z$는 $-\infty$부터 $\infty$까지 어떤 값이든 될 수 있으므로 그대로 확률로 사용할 수 없다. 이 값을 sigmoid 함수에 통과시킨다.

$$
p
=
\sigma(z)
=
\frac{1}{1+e^{-z}}
$$

유한한 $z$에 대해 sigmoid의 출력 범위는 다음과 같다.

$$
0<p<1
$$

대표적인 입력과 출력은 다음과 같다.

| $z$ | $\sigma(z)$ |
| ---: | ---: |
| $-10$ | 약 $0.00005$ |
| $0$ | $0.5$ |
| $10$ | 약 $0.99995$ |

전체 흐름은 다음과 같다.

```text
입력 X
  ↓
z = wᵀx + b
  ↓ sigmoid
양성 클래스의 추정 확률 p
  ↓ threshold
최종 클래스 0 또는 1
```

### 이름은 회귀인데 왜 분류 모델일까?

로지스틱 회귀는 양성일 확률 $p$ 자체보다 그 확률의 **로그 오즈(log-odds)를** 선형식으로 모델링한다.

$$
\log\left(\frac{p}{1-p}\right)
=
\mathbf{w}^\top\mathbf{x}+b
$$

이 선형식으로부터 $p$를 구하고, 임계값을 적용해 클래스를 결정한다.

```python
probability = 0.43
threshold = 0.5
prediction = int(probability >= threshold)
```

연속적인 로그 오즈를 모델링하지만 최종 목적은 클래스를 예측하는 것이므로 분류 모델이다.

### 임계값 0.5는 법칙이 아니다

모델이 고객의 이탈 확률을 $0.43$으로 예측했다고 하자.

- 임계값이 $0.5$이면 유지로 분류한다.
- 임계값이 $0.3$이면 이탈로 분류한다.

임계값을 낮추면 양성으로 분류하는 샘플 수가 늘어나므로 일반적으로 Recall은 유지되거나 증가한다. 반대로 임계값을 높이면 양성으로 분류하는 샘플 수가 줄어 Recall은 유지되거나 감소한다.

Precision은 새로 포함되거나 제외된 샘플의 실제 클래스에 따라 변동하므로 반드시 한 방향으로만 움직이지는 않는다. 임계값은 오류 비용과 처리 용량을 고려해 Validation 데이터에서 선택한다.

### 선형 모델의 장점과 한계

| 관점 | 특징 |
| --- | --- |
| 장점 | 빠르고 비교적 단순하며 계수를 확인할 수 있음 |
| 잘 맞는 관계 | 입력 특성의 가중합으로 근사할 수 있는 관계 |
| 한계 | 복잡하게 휘어진 관계나 조건 조합을 그대로 표현하기 어려움 |
| 스케일링 | 예측 자체에는 항상 필수는 아니지만, 규제·최적화·계수 비교에서는 중요할 수 있음 |
| 첫 후보 | 빠르고 해석 가능한 baseline이 필요할 때 |

선형 모델의 계수는 모델 내부의 방향과 크기를 보여 주지만, 곧바로 인과관계를 뜻하지는 않는다. 규제 산업에서도 설명 가능성뿐 아니라 데이터 품질, 편향, 안정성, 성능을 함께 검토해야 한다.

## KNN

### 가까운 이웃을 참고한다

**K-최근접 이웃(K-Nearest Neighbors, KNN)은** 새로운 샘플과 가장 가까운 $K$개의 학습 샘플을 찾아 예측한다.

- 분류: 이웃 클래스의 다수결 또는 거리 가중 투표
- 회귀: 이웃 목표값의 평균 또는 거리 가중 평균

예를 들어 새로운 샘플 ★의 가까운 이웃 세 개가 ●, ●, ○라면 $K=3$인 KNN 분류기는 다수결로 ★를 ● 클래스라고 예측한다.

```text
●        ●

      ★
   ●      ○
       ●

가장 가까운 3개: ●, ●, ○
예측 클래스: ●
```

### 학습보다 예측 시점의 계산이 많다

KNN의 `fit()`은 주로 학습 데이터를 저장한다. 새로운 입력이 들어오면 다음 과정을 수행한다.

1. 학습 샘플과 새 입력 사이의 거리를 계산한다.
2. 가장 가까운 $K$개를 선택한다.
3. 분류는 투표, 회귀는 평균으로 예측한다.

그래서 KNN을 **지연 학습(lazy learning)이라고** 부르기도 한다.

| 단계 | 특징 |
| --- | --- |
| 학습 | 상대적으로 빠름 |
| 예측 | 학습 샘플이 많으면 느려질 수 있음 |
| 메모리 | 학습 데이터를 저장해야 하므로 사용량이 커질 수 있음 |

### 거리와 스케일링

대표적인 유클리드 거리(Euclidean distance)는 다음과 같다.

$$
d(\mathbf{x},\mathbf{x}')
=
\sqrt{
\sum_{j=1}^{d}
\left(x_j-x'_j\right)^2
}
$$

두 사람의 특성이 나이와 연봉이라고 하자.

```text
A = [30세, 40,000,000원]
B = [40세, 60,000,000원]

나이 차이 = 10
연봉 차이 = 20,000,000
```

원 단위를 그대로 사용하면 연봉 차이가 거리 계산을 거의 지배한다. 나이가 중요한 특성이어도 수치 범위가 작다는 이유로 영향이 사라질 수 있다.

따라서 거리 기반 모델에서는 특성 스케일링을 중요하게 검토한다. `StandardScaler`는 각 특성 $j$를 다음처럼 표준화한다.

$$
z_{ij}
=
\frac{x_{ij}-\mu_j}{s_j}
$$

- $\mu_j$: Train 데이터에서 계산한 $j$번째 특성의 평균
- $s_j$: Train 데이터에서 계산한 $j$번째 특성의 표준편차

표준화하면 각 특성은 평균 $0$, 표준편차 $1$에 가까운 범위를 갖는다. 전처리기가 Validation이나 Test 정보를 보지 않게 `Pipeline`으로 묶는 것이 안전하다.

```python
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

knn = make_pipeline(
    StandardScaler(),
    KNeighborsClassifier(n_neighbors=5),
)
```

### $K$가 모델 복잡도를 조절한다

$K=1$이면 가장 가까운 샘플 하나만 참고하므로 매우 세밀한 경계를 만들 수 있지만 노이즈에도 민감하다.

```text
K가 작음
→ 복잡하고 들쭉날쭉한 경계
→ 낮은 bias, 높은 variance
→ 과적합 위험 증가
```

$K$가 매우 크면 많은 이웃의 평균적인 경향을 따르므로 경계가 부드러워지지만 지역적인 패턴을 놓칠 수 있다.

```text
K가 큼
→ 부드러운 경계
→ 높은 bias, 낮은 variance
→ 과소적합 위험 증가
```

적절한 $K$는 Validation 데이터나 교차 검증으로 선택한다.

### 차원의 저주

특성 수가 커지면 공간의 부피가 빠르게 증가하고 데이터가 희소해진다. 그러면 가장 가까운 이웃과 먼 이웃의 거리 차이가 상대적으로 작아져 “가까운 샘플은 비슷할 것”이라는 KNN의 가정이 약해질 수 있다. 이를 **차원의 저주(curse of dimensionality)라고** 한다.

따라서 “데이터가 적으면 무조건 KNN”이라는 규칙은 옳지 않다. 샘플 수 $n$과 특성 수 $d$를 함께 보고, 불필요한 특성 제거·차원 축소·거리 척도 변경 등을 검토해야 한다.

## 결정 트리

### 조건문으로 특성 공간을 나눈다

**결정 트리(Decision Tree)는** 데이터를 잘 나눌 수 있는 질문을 반복해서 찾는다.

```text
나이 < 30?
├── Yes → 소득 < 4,000?
│          ├── Yes → A
│          └── No  → B
└── No  → C
```

질문 하나는 특성 공간을 한 번 자르는 것과 같다. 예를 들어 첫 번째 특성 $x_1$을 기준으로 나눈 뒤 두 번째 특성 $x_2$로 다시 나눌 수 있다.

```text
x₁ < 5?
├── Yes → A
└── No  → x₂ < 5?
           ├── Yes → C
           └── No  → B
```

이처럼 축에 평행한 분할을 여러 개 조합하면 하나의 직선으로 표현하기 어려운 비선형 경계도 만들 수 있다.

### 좋은 분할을 찾는 기준

분류 트리는 각 분할 뒤의 노드가 가능한 한 한 종류의 클래스로 이루어지도록 질문을 선택한다. 대표적인 불순도 기준은 다음과 같다.

- Gini impurity
- Entropy

```text
분할 전: ● ● ○ ● ○ ○
분할 후: ● ● ● | ○ ○ ○
```

분할 후의 불순도가 많이 감소할수록 좋은 질문이다. 회귀 트리는 보통 평균 제곱 오차와 같은 기준으로 목표값이 비슷한 샘플끼리 묶이도록 분할한다.

### 결정 트리와 스케일링

결정 트리는 거리보다 값의 순서와 임계값을 사용한다.

```text
연봉 < 50,000,000?
```

연봉을 만 원 단위로 바꾸면 임계값도 함께 바뀌지만 샘플의 순서는 그대로다. 따라서 일반적인 결정 트리는 StandardScaler가 거의 필요하지 않다.

### 깊어질수록 과적합하기 쉽다

트리를 제한 없이 성장시키면 학습 샘플 하나하나를 구분하는 매우 세밀한 규칙을 만들 수 있다.

```text
Train Accuracy = 100%
Test Accuracy  = 낮음
```

이런 과적합을 줄이기 위해 다음과 같은 하이퍼파라미터로 복잡도를 제한한다.

- `max_depth`: 트리의 최대 깊이
- `min_samples_split`: 노드를 나누기 위한 최소 샘플 수
- `min_samples_leaf`: 잎 노드가 가져야 할 최소 샘플 수
- `ccp_alpha`: 비용 복잡도 가지치기의 강도

결정 트리는 규칙을 따라가며 예측 이유를 설명하기 쉽지만, 데이터가 조금 바뀌어도 구조가 크게 달라질 수 있는 높은 variance를 가질 수 있다. Random Forest와 Gradient Boosting은 여러 트리를 결합해 단일 트리의 한계를 보완한다.

## K-Means

### KNN과 K-Means는 다른 방법이다

이름에 $K$가 들어간다는 점만 같을 뿐 학습 방식과 목적은 다르다.

| 구분 | KNN | K-Means |
| --- | --- | --- |
| 학습 종류 | 지도학습 | 비지도학습 |
| $y$ 사용 | 사용함 | 사용하지 않음 |
| $K$의 의미 | 참고할 이웃 수 | 만들 군집 수 |
| 결과 | 클래스 또는 연속값 예측 | 샘플의 군집 할당 |

### 가장 가까운 중심점에 샘플을 배정한다

**K-Means는** $K$개의 중심점(centroid)을 기준으로 비슷한 샘플을 묶는다.

1. 중심점 $K$개를 초기화한다.
2. 각 샘플을 가장 가까운 중심점에 배정한다.
3. 각 군집에 속한 샘플의 평균 위치로 중심점을 이동한다.
4. 배정과 중심 이동을 수렴할 때까지 반복한다.

```text
중심 초기화
    ↓
가장 가까운 중심에 배정
    ↓
군집별 평균으로 중심 이동
    ↓
수렴할 때까지 반복
```

각 중심점이 해당 군집 샘플의 평균이기 때문에 이름에 Means가 들어간다.

K-Means는 다음과 같은 군집 내부 제곱 거리의 합을 줄이는 방향으로 작동한다.

$$
\sum_{i=1}^{n}
\left\lVert
\mathbf{x}_i-\boldsymbol{\mu}_{c_i}
\right\rVert_2^2
$$

- $c_i$: $i$번째 샘플이 배정된 군집
- $\boldsymbol{\mu}_{c_i}$: 해당 군집의 중심점

### K-Means도 스케일링에 민감하다

K-Means는 중심점과의 거리를 사용하므로 수치 범위가 큰 특성이 군집 결과를 지배할 수 있다.

```python
from sklearn.cluster import KMeans
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

kmeans = make_pipeline(
    StandardScaler(),
    KMeans(n_clusters=3, n_init=10, random_state=42),
)
```

다만 스케일링은 모든 특성을 같은 중요도로 취급하겠다는 모델링 선택이기도 하다. 특성의 단위와 업무적 의미를 먼저 확인해야 한다.

### 군집 수 $K$를 고르는 방법

이론적으로 최적화된 군집 내부 제곱 거리의 합은 $K$를 늘릴수록 감소하거나 유지된다. 따라서 거리만 가장 작게 만드는 $K$를 찾으면 결국 샘플 수만큼 군집을 만들 수 있다.

대표적인 보조 방법은 다음과 같다.

- Elbow method: $K$ 증가에 따른 inertia 감소 폭이 급격히 줄어드는 지점 확인
- Silhouette coefficient: 같은 군집 안에서는 가깝고 다른 군집과는 먼 정도를 평가
- 업무 목적: 실제로 해석하고 사용할 수 있는 군집 수인지 확인

Elbow가 뚜렷하지 않을 수도 있으므로 하나의 그래프만으로 객관적인 정답이 결정된다고 생각하면 안 된다.

### K-Means의 한계

K-Means는 유클리드 거리와 평균 중심을 사용하므로 대체로 둥글고 크기와 밀도가 비슷한 군집에 잘 맞는다.

- 굽은 모양이나 복잡한 모양의 군집을 놓칠 수 있다.
- 이상치가 평균 중심을 크게 이동시킬 수 있다.
- 초기 중심에 따라 서로 다른 지역 최적해에 도달할 수 있다.
- 범주형 특성에는 유클리드 평균이 자연스럽지 않을 수 있다.
- 알고리즘이 만든 군집이 현실에 객관적으로 존재하는 집단이라는 보장은 없다.

따라서 여러 초기값으로 실행하고, 안정성·해석 가능성·실제 활용성을 함께 확인해야 한다.

## PCA

### 데이터가 많이 퍼진 방향을 새 축으로 삼는다

**주성분 분석(Principal Component Analysis, PCA)은** 중심화한 데이터를 선형 투영할 때 분산을 최대한 보존하는 서로 직교한 방향을 찾는 차원 축소 방법이다.

2차원 데이터가 대각선 방향으로 길게 퍼져 있다고 하자.

```text
x₂
│                 •
│             •
│          •
│       •
│    •
│ •
└────────────────── x₁
```

PCA는 데이터가 가장 많이 퍼진 방향을 첫 번째 주성분인 PC1로 선택한다. 그다음으로 많이 퍼진 방향 중 PC1과 직교하는 방향을 PC2로 선택한다.

```text
PC1 ↗ : 데이터가 가장 많이 퍼진 방향
PC2 ↖ : PC1과 직교하면서 그다음으로 많이 퍼진 방향
```

### 분산을 보존한다는 의미

특성이 100개여도 서로 비슷한 정보를 담고 있다면 소수의 새로운 축으로 데이터의 변화를 상당 부분 표현할 수 있다.

```text
원래 특성 100개
      ↓ PCA
주성분 10개
```

설명 분산 비율이 다음과 같다고 하자.

```text
PC1: 60%
PC2: 20%
PC3: 10%
나머지: 10%
```

PC1부터 PC3까지 사용하면 전체 분산의 90%를 보존한다. PCA는 원래 특성 몇 개를 그대로 고르는 것이 아니라, 원래 특성의 선형 결합으로 새로운 축을 만든다.

### PCA와 SVD의 연결

샘플이 $n$개, 특성이 $d$개인 데이터를 특성별 평균으로 중심화한 행렬을 $X_c$라고 하자.

$$
X_c\in\mathbb{R}^{n\times d}
$$

축약형 SVD를 적용하면 다음과 같다.

$$
X_c=U\Sigma V^\top
$$

| 행렬 | 크기 | PCA에서의 의미 |
| --- | --- | --- |
| $U$ | $n\times r$ | 샘플과 주성분 방향의 관계 |
| $\Sigma$ | $r\times r$ | 방향별 특이값 |
| $V$ | $d\times r$ | 특성 공간의 주성분 방향 |

여기서 $r=\min(n,d)$다. $V$의 열벡터가 주성분 방향이 되고, $i$번째 방향의 표본 분산은 특이값 $\sigma_i$와 다음처럼 연결된다.

$$
\lambda_i
=
\frac{\sigma_i^2}{n-1}
$$

특이값이 큰 방향일수록 데이터의 분산이 크다. 따라서 상위 $k$개의 특이값과 방향만 남기는 SVD의 저랭크 근사와 PCA 차원 축소가 연결된다.

### PCA와 스케일링

PCA는 분산이 큰 방향을 우선한다. 나이가 $20$에서 $60$ 사이이고 연봉이 수천만 원에서 수억 원 사이라면, 원 단위 연봉의 분산이 수치적으로 압도적일 수 있다.

서로 다른 단위의 특성을 동일한 중요도로 비교하려면 PCA 전에 StandardScaler를 적용할 수 있다.

```python
from sklearn.decomposition import PCA
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

pca = make_pipeline(
    StandardScaler(),
    PCA(n_components=2),
)
```

하지만 스케일링이 수학적으로 항상 필수인 것은 아니다. 원래 단위의 분산 차이 자체가 중요한 정보라면 표준화가 그 의미를 바꿀 수 있다. scikit-learn의 `PCA`는 입력을 중심화하지만 특성별 표준편차로 나누지는 않는다.

### 분산이 크다고 예측에 중요한 것은 아니다

PCA는 목표값 $y$를 보지 않는다. 따라서 분산이 큰 방향이 지도학습 문제의 예측에 중요한 방향이라는 보장은 없다.

```text
PC1: 전체 분산의 95%, 클래스 구분과 무관
PC2: 전체 분산의  5%, 클래스 구분에 중요
```

이런 데이터에서 PC1만 남기면 분산은 많이 보존하지만 중요한 분류 신호를 잃을 수 있다. PCA 적용 여부와 주성분 수는 최종 지도학습 성능을 Validation 데이터나 교차 검증으로 확인해야 한다.

## 모델 비교

| 모델 | 문제 유형 | 핵심 판단 기준 | 스케일링 | 장점 | 주요 한계 |
| --- | --- | --- | --- | --- | --- |
| Linear Regression | 회귀 | 특성의 가중합 | 상황에 따라 | 빠르고 계수 확인이 쉬움 | 복잡한 비선형 관계에 약함 |
| Logistic Regression | 분류 | 가중합을 확률로 변환 | 대체로 권장 | 빠르고 좋은 baseline | 복잡한 결정 경계에 약함 |
| KNN | 회귀·분류 | 가까운 $K$개 이웃 | 중요 | 직관적이고 비선형 경계 가능 | 예측 비용, 고차원, 스케일에 민감 |
| Decision Tree | 회귀·분류 | 반복적인 조건 분할 | 거의 불필요 | 비선형 관계와 규칙 설명에 유리 | 깊어지면 과적합, 구조가 불안정할 수 있음 |
| K-Means | 군집화 | 가까운 중심점 | 중요 | 간단하고 직관적인 군집화 | $K$와 군집 모양에 대한 가정 필요 |
| PCA | 차원 축소 | 분산이 큰 직교 방향 | 데이터 의미에 따라 | 압축·시각화·중복 감소 | $y$를 보지 않아 예측 신호를 잃을 수 있음 |

지도학습 모델 세 가지의 질문을 짧게 비교하면 다음과 같다.

```text
Linear / Logistic → 이 특성들을 얼마씩 더할까?
KNN              → 이 샘플 주변에는 누가 있을까?
Decision Tree    → 어떤 조건으로 나누면 좋을까?
```

## 모델 선택 기준

### 설명 가능성이 중요할 때

빠르고 비교적 단순한 baseline과 계수 해석이 필요하다면 Linear Regression이나 Logistic Regression을 먼저 고려할 수 있다. 조건 규칙의 흐름을 보여 주는 방식이 더 적절하다면 깊이를 제한한 Decision Tree도 후보가 된다.

다만 “설명 가능하다”는 말은 모델 구조를 추적하기 쉽다는 뜻이지, 예측이 공정하거나 계수가 인과 효과라는 뜻은 아니다.

### 비선형 관계가 강할 때

특성 값이 증가할수록 목표값이 항상 같은 방향으로 변하지 않거나 여러 조건의 조합이 중요하다면 KNN이나 Decision Tree가 선형 모델보다 관계를 쉽게 표현할 수 있다.

선형 모델도 다항 특성, 상호작용 항, 비선형 변환을 추가하면 비선형 패턴을 일부 표현할 수 있다. 따라서 모델 이름만 보고 표현력을 단정하기보다 사용한 특성 표현까지 확인해야 한다.

### 스케일링이 어렵거나 불필요하게 만들고 싶을 때

일반적인 결정 트리는 특성의 순서를 기준으로 분할하므로 스케일링이 거의 필요하지 않다. 반면 다음 방법은 크기나 분산을 직접 사용하므로 스케일의 영향을 확인해야 한다.

- KNN: 샘플 사이의 거리
- K-Means: 샘플과 중심 사이의 거리
- PCA: 특성별 분산
- 규제가 있는 선형 모델: 계수 크기에 적용되는 벌점

### 샘플과 특성의 수를 함께 볼 때

KNN은 학습 데이터가 커지면 예측 시 거리 계산 비용과 메모리 사용량이 커질 수 있다. 특성 수가 매우 많으면 차원의 저주로 거리 자체의 구분력도 약해질 수 있다.

반면 선형 모델은 고차원 희소 데이터에서도 강한 baseline이 될 수 있으며, 트리는 복잡한 상호작용을 잡을 수 있지만 깊이와 샘플 수를 함께 조절해야 한다.

### 첫 후보와 최종 선택을 구분한다

데이터 특성을 보고 고른 모델은 **첫 후보일 뿐이다**. 최종 선택은 같은 데이터 분할과 같은 평가지표에서 공정하게 비교해야 한다.

1. 문제 유형과 목표값 $y$를 확인한다.
2. 해석 가능성, 비선형성, 데이터 크기와 차원을 확인한다.
3. 거리·분산 기반 방법이라면 스케일링 필요성을 검토한다.
4. 단순한 baseline과 몇 개의 합리적인 후보를 정한다.
5. 전처리를 `Pipeline`에 포함한다.
6. Validation 데이터나 교차 검증으로 하이퍼파라미터와 모델을 선택한다.
7. 모든 선택을 확정한 뒤 Test 데이터에서 최종 평가한다.

## 직접 확인

NumPy로 선형 모델의 행렬곱과 sigmoid 출력을 확인한다.

```python
import numpy as np

X = np.array(
    [
        [50.0, 0.5, 10.0],
        [70.0, 1.0, 5.0],
    ]
)
w = np.array([0.08, -0.3, -0.05])
b = 1.2

y_pred = X @ w + b

z = np.array([-2.0, 0.0, 2.0])
probability = 1 / (1 + np.exp(-z))

print("X shape:", X.shape)
print("w shape:", w.shape)
print("prediction shape:", y_pred.shape)
print("linear prediction:", y_pred)
print("sigmoid:", np.round(probability, 4))
```

실행 결과:

```text
X shape: (2, 3)
w shape: (3,)
prediction shape: (2,)
linear prediction: [4.55 6.25]
sigmoid: [0.1192 0.5    0.8808]
```

행렬곱 `X @ w`에서는 $X$의 특성 축 크기 3과 $\mathbf{w}$의 원소 수 3이 대응한다. 그 결과 두 샘플에 대한 예측값 두 개가 남아 shape은 $(2,)$가 된다.

## 헷갈리기 쉬운 부분

| 헷갈리기 쉬운 생각 | 정확한 이해 |
| --- | --- |
| Linear Layer는 항상 엄밀한 선형 변환이다 | 편향이 포함된 `XW+b`는 엄밀히는 아핀 변환이지만 관습적으로 Linear Layer라고 부른다 |
| Logistic Regression은 이름 때문에 회귀 모델이다 | 로그 오즈를 선형식으로 모델링하지만 최종적으로 클래스를 예측한다 |
| 임계값을 낮추면 Precision은 반드시 감소한다 | Recall은 유지되거나 증가하지만 Precision은 새로 포함된 샘플에 따라 변동할 수 있다 |
| KNN과 K-Means는 비슷한 모델이다 | KNN은 $y$를 쓰는 지도학습, K-Means는 $y$를 쓰지 않는 군집화다 |
| 데이터가 적으면 KNN이 항상 좋다 | 특성 수가 많으면 차원의 저주 때문에 이웃의 의미가 약해질 수 있다 |
| 결정 트리도 거리 모델처럼 표준화해야 한다 | 일반적인 트리는 값의 순서와 임계값을 사용하므로 스케일링이 거의 필요하지 않다 |
| PCA가 분산을 많이 보존하면 예측 성능도 좋아진다 | PCA는 $y$를 보지 않으므로 낮은 분산의 중요한 예측 신호를 버릴 수 있다 |
| K-Means가 찾은 군집은 현실의 객관적인 집단이다 | 결과는 거리, 스케일, $K$, 초기값과 데이터 표현에 따라 달라진다 |

## 실제 활용

### 빠른 baseline 만들기

회귀는 Linear Regression, 분류는 Logistic Regression으로 시작하면 복잡한 모델이 실제로 얼마나 개선되는지 비교할 기준을 만들 수 있다.

### 고객 이탈 예측

Logistic Regression으로 빠르고 해석 가능한 기준 성능을 만든 뒤 Decision Tree와 비교할 수 있다. 거리 기반 KNN도 후보가 될 수 있지만 샘플 수, 차원, 예측 비용, 스케일링을 함께 확인해야 한다.

### 고객 세분화

레이블이 없다면 K-Means로 고객을 묶어 볼 수 있다. 이때 군집 수와 스케일을 바꾸어도 결과가 안정적인지, 만들어진 군집이 실제 마케팅이나 서비스 개선에 사용할 수 있는지 확인한다.

### 고차원 데이터 탐색

PCA로 차원을 줄여 시각화하거나 선형 모델의 전처리 후보로 사용할 수 있다. 다만 PCA를 포함한 전체 Pipeline을 교차 검증해 실제 목표 지표가 개선되는지 확인해야 한다.

### 딥러닝과 Transformer

선형 모델의 핵심 연산인 행렬곱과 편향은 신경망의 Linear Layer에도 반복해서 등장한다. PCA와 SVD의 저랭크 관점은 임베딩 분석, 압축, 추천 시스템, LoRA 같은 후속 주제를 이해하는 기반이 된다.
