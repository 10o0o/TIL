# Reviews

`reviews/`는 학습 직후의 느낌이 아니라 **시간이 지난 뒤에도 지식이 남아 있는지** 확인합니다.

## 경로

```text
reviews/YYYY-Www.md
```

## 간격 반복

핵심 개념은 다음 시점에 확인합니다.

- 1일: 정의와 필요성
- 3일: 작은 숫자 또는 shape
- 7일: 새로운 응용
- 14일: 다른 개념과 연결한 설명

## 주간 리뷰

다음을 자료 없이 먼저 답합니다.

1. 이번 주에 가장 중요한 개념 세 개는 무엇인가?
2. 각 개념이 해결하는 문제는 무엇인가?
3. 수식 또는 Tensor shape을 설명할 수 있는가?
4. 코드 없이 결과를 예측할 수 있는가?
5. 다시 막힌 prerequisite는 무엇인가?
6. LLM Systems, Post-training, Evaluation과 어떻게 연결되는가?

그 뒤 노트와 실험을 확인하고 `curriculum/progress.md`의 상태를 올리거나 내립니다.

[templates/weekly-review.md](../templates/weekly-review.md)를 사용합니다.
