## 오늘의 학습

### 행렬 곱과 완전연결층

행렬 곱의 각 결과 원소는 앞 행렬의 한 행과 뒤 행렬의 한 열의 내적이다. 따라서 행렬 곱은 여러 내적을 한 번에 계산한다.

완전연결층의 기본 계산은 다음과 같다.

```python
X @ W + b
```

여기서 가중치가 `W.shape = (입력, 출력) = (3, 2)`일 때, `nn.Linear(3, 2)`가 실제로 저장하는 매개변수의 shape은 다음과 같다.

```python
layer.weight.shape  # (출력, 입력) = (2, 3)
layer.bias.shape    # (출력,) = (2,)
```

따라서 PyTorch 내부 계산을 NumPy 식으로 적으면 다음과 같다.

```python
X @ layer.weight.T + layer.bias
```

PyTorch에서는 다음과 같이 가져와 사용한다.

```python
import torch
import torch.nn as nn
```

`torch`는 PyTorch 패키지이고, `torch.nn`은 신경망 구성 요소가 모여 있는 하위 패키지다. `as nn`은 `torch.nn`을 `nn`이라는 이름으로 사용한다는 뜻이다.

`Linear`는 입력 벡터를 새로운 크기의 출력 벡터로 변환하는 PyTorch 클래스다.

```python
layer = nn.Linear(3, 2)
```

여기서 `3 = in_features`는 입력 벡터의 성분 수이고, `2 = out_features`는 출력 벡터의 성분 수다. 즉 숫자 3개를 입력받아 숫자 2개를 출력하는 완전연결층을 만든다.

`layer` 안에는 PyTorch가 생성한 학습 대상인 `weight`와 `bias`가 들어 있다.

```python
layer.weight.shape  # (2, 3)
layer.bias.shape    # (2,)
```

출력값이 2개이므로 가중치의 행이 2개다. 각 출력이 입력 성분 3개를 모두 사용하므로 행마다 가중치가 3개다. 출력마다 편향 하나가 있으므로 편향은 2개다.

`weight`와 `bias`는 학습 과정에서 값이 바뀌는 매개변수다. PyTorch의 `nn.Module`은 이러한 매개변수를 자동으로 등록하고 관리한다.

`nn.Linear(4, 3)`은 특정 계산 결과가 아니라 입력 4개를 받아 출력 3개를 만드는 계산기다.

```python
layer = nn.Linear(4, 3)
```

`layer` 안에는 `in_features`, `out_features`, `weight`, `bias` 등의 정보가 들어간다. `4`, `3`은 저장될 값을 직접 결정하지 않고 매개변수의 shape을 결정한다.

### 특수 행렬과 행렬 연산의 성질

단위행렬은 곱해도 아무 변화가 없는 행렬이다.

대각행렬은 주대각선 이외의 원소가 모두 0이다. 각 성분을 독립적으로 확대하거나 축소하고, 부호를 반전할 수 있다. 딥러닝에서 특성별로 서로 다른 값을 곱하는 연산은 대각행렬 곱과 비슷하게 볼 수 있다.

```python
scale = torch.tensor([2.0, 0.5, -1.0])
y = x * scale
```

이는 개념적으로 대각행렬을 곱하는 것과 같다.

대칭행렬은 전치해도 자기 자신과 같다. 모든 대각행렬은 대칭행렬이다. 일반 대칭행렬은 대각선 밖에도 값이 있을 수 있어 성분을 섞지만, 대각행렬은 각 성분에 독립적으로 작용한다.

행렬 곱은 일반적으로 교환법칙이 성립하지 않는다. 단위행렬처럼 특정한 경우에는 순서를 바꿔도 결과가 같다.

행렬 곱을 전치하면 각 행렬을 전치하고 곱하는 순서를 바꿔야 한다.

```python
(A @ B).T == B.T @ A.T
```

역행렬은 변환을 되돌린다. 하지만 모든 행렬을 되돌릴 수 있는 것은 아니다. 정사각행렬은 `det = 0`일 때 역행렬이 없다. `2×2` 행렬에서는 `det = ad - bc`로 계산한다.

2차원에서 `abs(det)`는 넓이의 배율이다. `det = 0`이면 넓이가 0이 되어 공간이 선이나 점으로 붕괴하므로, 원래 입력을 구별하여 되돌릴 수 없게 된다.

`det`가 작다는 것만으로 수치적으로 불안정하다고 판단할 수는 없다. 모든 방향을 같은 비율로 축소하면 `det`는 작아도 조건수는 1일 수 있다. 방향별 확대·축소 비율의 차이를 나타내는 조건수를 함께 봐야 한다.

### 선형 변환과 기저벡터

2차원 벡터는 서로 평행하지 않은 두 방향을 조합해서 만들 수 있다. 공간 전체를 만들 수 있으면서 서로 선형 독립인 벡터 집합을 기저라고 한다.

행렬이 각 기저벡터를 어디로 보내는지만 알면 모든 벡터의 변환 결과가 결정된다. 선형 변환 `T`는 다음 두 조건을 만족한다.

$$
T(\mathbf{u}+\mathbf{v})=T(\mathbf{u})+T(\mathbf{v})
$$

$$
T(c\mathbf{u})=cT(\mathbf{u})
$$

예를 들어 `T(e1) = (2, 0)`, `T(e2) = (1, 1)`일 때 선형성에 의해 다음과 같이 계산했다.

$$
T(3\mathbf{e}_1-\mathbf{e}_2)
=3T(\mathbf{e}_1)-T(\mathbf{e}_2)
=(5,-1)
$$

모든 선형 변환은 `T(0) = 0`을 만족한다. 따라서 평행이동 `F(x) = Ax + t`에서 `t != 0`이면 `F(0) = t`가 되므로 선형 변환이 아니다.

### 벡터공간과 선형 독립

선형 독립은 각 벡터가 새로운 방향을 추가하는 것이고, 선형 종속은 어떤 벡터가 기존 방향의 조합이라 새 방향을 추가하지 못하는 것이다. 어떤 공간의 기저가 되려면 그 공간 전체를 span하면서 벡터들이 선형 독립이어야 한다. 2차원에서는 서로 평행하지 않은 두 벡터가 기저가 될 수 있다.

`v3 = v1 + v2`인 예에서는 `v3`가 새로운 방향을 추가하지 않는다. 따라서 세 벡터는 선형 종속이고, `v1`과 `v2`가 독립이라면 이들을 열로 세운 행렬의 rank는 2이다.

rank는 변환 뒤에 살아남은 독립 방향의 수로 이해했다.

```text
열공간: A가 만들어 낼 수 있는 출력들의 집합
영공간: A가 0으로 보내는 입력들의 집합
rank:   출력에 살아남은 독립 방향의 수
```

영공간은 다음 식을 만족하는 모든 입력의 집합이다.

$$
A\mathbf{x}=\mathbf{0}
$$

### 연립방정식의 해와 최소제곱

`Ax = b`의 해는 `b`가 `A`의 열공간 안에 있는지와 독립적인 변수 방향이 몇 개인지에 따라 달라진다.

```text
rank(A) < rank([A, b])
→ b가 열공간 밖에 있음
→ 해 없음

rank(A) = rank([A, b]) = n
→ b를 만들 수 있고 모든 변수 방향이 독립적
→ 유일해

rank(A) = rank([A, b]) < n
→ b를 만들 수 있지만 자유변수가 남음
→ 무한해
```

열벡터가 `(1, 2)`, `(2, 4)`인 행렬에서 `b1 = (3, 6)`은 열공간 안에 있지만 rank가 변수 수보다 작으므로 해가 무한히 많다. 반면 `b2 = (3, 7)`은 열공간 밖에 있으므로 해가 없다.

최소제곱은 `b`와 정확히 같은 출력을 찾는 대신, 오차의 제곱합이 가장 작아지도록 `b`에 가장 가까운 `Ax`를 찾는다.

`A`의 열벡터가 `(1, 1)`이고 `b = (2, 6)`인 예에서는 `x = 4`일 때 `Ax = (4, 4)`가 된다. 이때 잔차는 다음과 같다.

$$
\mathbf{r}
=\mathbf{b}-A\mathbf{x}
=(-2,2)
$$

잔차와 열벡터의 내적은 `0`이다.

$$
(-2,2)\cdot(1,1)=0
$$

잔차가 열공간 방향의 성분을 가지고 있다면 `Ax`를 그 방향으로 더 움직여 오차를 줄일 수 있다. 따라서 더 이상 오차를 줄일 수 없는 최소제곱 해에서는 잔차가 열공간과 직교한다.

이 직교 조건을 식으로 나타낸 것이 정규방정식이다.

$$
A^T A\mathbf{x}=A^T\mathbf{b}
$$

## 배운 점

`nn.Linear`에 전달하는 입력·출력 차원은 계산 결과를 미리 정하는 값이 아니라, 객체 안에 저장될 `weight`와 `bias`의 shape을 정한다. 만들어진 하나의 `layer` 객체는 자신이 가진 같은 매개변수를 호출할 때마다 다시 사용한다.

대각행렬은 성분별로 독립적으로 작용하지만, 일반 대칭행렬은 대각선 밖의 값을 통해 성분을 섞을 수 있다. 또한 행렬 곱은 일반적으로 순서에 따라 결과가 달라지므로, 연산이나 신경망 층의 순서를 함부로 바꿀 수 없다.

역행렬의 존재 여부와 수치적 안정성은 구분해야 한다. `det = 0`이면 역행렬이 없지만, `det`의 크기만으로 불안정성을 판단할 수는 없다.

행렬의 열은 기저벡터가 변환된 결과이며, 선형성 덕분에 임의의 벡터도 그 열들의 선형결합으로 변환할 수 있다.

선형 종속인 벡터는 새로운 방향을 추가하지 않으므로 rank를 늘리지 않는다. 이 관점으로 `b`가 열공간 안에 있는지와 rank를 함께 확인하면 연립방정식의 유일해, 무한해, 해 없음을 구분할 수 있다.

정확한 해가 없을 때 최소제곱은 `b`에 가장 가까운 `Ax`를 찾는다. 최적점의 잔차가 열공간과 직교해야 하는 이유도 오차를 더 줄일 수 있는 방향이 남아 있지 않아야 하기 때문이라고 이해했다.
