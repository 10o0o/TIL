# TIL

`til/`은 강의 전체를 요약하는 장소가 아니라 **그날 바뀐 이해의 변경 로그**입니다.

## 작성할 때

- 이전의 오개념이 수정됨
- 설명하지 못하던 개념을 설명하게 됨
- 실험 결과가 예상과 달랐음
- 다음 학습을 막는 질문이 명확해짐

단순히 수업을 들었다는 이유로 매일 작성할 필요는 없습니다.

## 경로

```text
til/YYYY-MM/YYYY-MM-DD.md
```

## 분량

기본 5~15줄입니다. 길어지면 다음처럼 분리합니다.

- 재사용할 개념 설명 → `concepts/`
- 실행 코드와 출력 → `labs/`
- 복습 결과 → `reviews/`
- 과거 강의 원문 → `content/`

## 최소 구성

1. 자료 없이 기억한 것
2. 이전에 틀리거나 애매했던 것
3. 수정된 이해
4. 이해의 증거
5. 아직 남은 질문 또는 다음 복습일

[templates/til.md](../templates/til.md)를 사용합니다.
