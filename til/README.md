# TIL

공부한 내용을 나중에 다시 찾을 수 있도록 짧게 정리합니다.

```text
til/<area>/YYYY-MM-DD-<topic>.md
```

주제 폴더는 필요할 때만 만듭니다.

```text
math/
ml/
deep-learning/
llm/
systems/
```

한 노트에는 다음만 적으면 충분합니다.

1. 배운 것
2. 확인하거나 고친 것
3. 직접 해본 것
4. 다음에 볼 것

해당 내용이 없으면 섹션을 지웁니다. 매일 써야 할 의무도 없고, 짧은 코드 때문에 별도 실습 폴더를 만들 필요도 없습니다. [TIL 템플릿](../templates/til.md)을 복사해서 사용합니다.
