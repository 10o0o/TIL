# Practice

직접 실행한 코드와 실험을 모아둡니다.

```text
practice/<area>/<topic>/
```

예:

```text
practice/math/vector-normalization/
practice/ml/kaggle-titanic/
practice/llm/attention-score/
```

작은 코드 몇 줄은 TIL 안에 적어도 됩니다. 코드, 데이터 처리, 출력이 길어질 때만 별도 폴더를 만듭니다.

각 실습에는 질문, 실행 방법, 실제 결과, 배운 점만 남깁니다. 데이터셋, 모델 가중치, API 키와 큰 출력 파일은 Git에 올리지 않습니다.
