# Source Index

ChatGPT 프로젝트에 업로드한 KANT PDF와 수업 자료를 추적하는 인덱스입니다.

PDF 원본 자체를 이 저장소에 중복 저장할 필요는 없습니다. 파일명, 날짜, 핵심 개념, 중복 관계만 관리합니다.

## 등록 형식

| ID | 날짜 | 자료명 | 핵심 개념 | 선수지식 | 중복·연결 | 처리 상태 |
|---|---|---|---|---|---|---|
| 예시 | YYYY-MM-DD | 강의 PDF 이름 | 개념 A, 개념 B | 선수지식 X | 관련 강의 또는 canonical note | `indexed` |

## 처리 상태

| 상태 | 의미 |
|---|---|
| `uploaded` | 프로젝트에 업로드됨 |
| `indexed` | 핵심 개념과 선수지식이 추출됨 |
| `mapped` | course map과 중복 관계에 반영됨 |
| `learning` | 현재 학습 중인 단위가 포함됨 |
| `covered` | 필요한 개념 학습이 완료되었지만 PDF 전체를 문서화했다는 뜻은 아님 |

## 현재 자료

아직 저장소에서 확인할 수 있는 PDF 원본 목록은 없습니다. 전체 PDF를 ChatGPT 프로젝트에 업로드한 뒤 [GUIDE.md](../GUIDE.md)의 curriculum map 요청 예시를 사용하고, 실제 파일명과 내용을 확인한 결과만 이 표에 반영합니다. 기존 노트의 파일명만으로 원본 강의 목록을 추정하지 않습니다.
