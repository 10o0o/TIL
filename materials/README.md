# Materials

강의 PDF와 원본 자료를 보관합니다.

저작권이 있거나 비공개인 자료는 `materials/private/`에 두며, 이 경로는 Git에서 제외됩니다.

현재 로컬 자료:

```text
materials/private/kant-basic-math/  # Notion 기초 수학 19강
```

각 PDF에는 Notion의 접힌 내용도 펼친 상태로 포함되어 있습니다. 파일 목록과 원본 링크는 같은 폴더의 로컬 `INDEX.md`에 있습니다.

자료를 그대로 복사해 공개 노트로 만들지 않고, 공부한 뒤 필요한 내용만 `til/`에 정리합니다.
